The transformer is a deep learning architecture introduced in the 2017 paper "Attention Is All You Need," which replaced the recurrent and convolutional layers used in earlier sequence models with a mechanism called self-attention. Self-attention allows the model to weigh the relevance of every token in an input sequence against every other token simultaneously, rather than processing tokens strictly in order, which makes transformers far more parallelizable and easier to train on large datasets using modern GPU and TPU hardware.

At the core of the architecture is the scaled dot-product attention mechanism, which computes query, key, and value vectors for each token. The similarity between a token's query vector and every other token's key vector determines how much attention that token pays to each other token, and these attention weights are used to compute a weighted sum of value vectors. Multi-head attention runs several of these attention computations in parallel with different learned projections, allowing the model to capture different types of relationships, such as syntactic structure versus long-range topical dependencies, at the same time.

Transformers are typically organized into stacked encoder and/or decoder blocks. Each block combines a multi-head attention layer with a position-wise feed-forward network, along with residual connections and layer normalization to stabilize training of very deep networks. Because self-attention has no inherent sense of token order, positional encodings are added to the input embeddings so the model can distinguish where each token falls in the sequence.

The architecture became the foundation for large language models, including the GPT and Claude model families, as well as vision transformers adapted for image classification and other non-text domains. Its main computational drawback is that standard self-attention scales quadratically with sequence length, which has motivated research into more efficient attention variants for handling very long input contexts.
